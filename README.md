# スクショ結合

スマートフォンで分割して撮ったスクリーンショットを、1 枚の縦長画像（全画面キャプチャ）に結合するブラウザツールです。

## 開発の背景

日本の IT 現場では、モバイル版画面のテストで「エビデンスはページ全体のキャプチャで」と求められることがよくあります。
しかし、端末は機種も画面サイズもさまざまで、全画面キャプチャに対応していない場合もあります。さらに、セキュリティ規定により、画像加工アプリを各自でインストールすることも認められていない現場が少なくありません。

結局、何枚にも分けて撮ったスクリーンショットを手作業でつなぎ合わせることになり、エビデンス作成に多くの時間を取られてしまいます。

このツールは、そうした現場の手間を減らすために作りました。ブラウザで開くだけで使え、インストールは不要です。画像はすべてブラウザ内で処理され、外部のサーバーには一切アップロードされないため、社外秘の画面でも安心して扱えます。

## 主な機能

- **画像の読み込み**：クリックで選択、ドラッグ＆ドロップ、Ctrl+V での貼り付けに対応。複数枚をまとめて読み込むと、ファイル名順に横一列に並びます。
- **トリミング**：各画像の上下の線をドラッグして使う範囲を選び（ピクセル値の直接入力も可）、「確定」でプレビューに追加します。
- **プレビュー**：選んだ範囲を順番どおり縦につなげて表示します。ドラッグでの並べ替え、上下移動、削除ができます。
- **自動結合**：隣り合うスクリーンショットの重なりを自動で検出してつなぎ目を決め、途中に写り込んだステータスバー・アドレスバー・下部ツールバーを取り除きます。
  - 右上の「自動結合」：読み込んだ画像すべてを結合
  - 各画像の下の「ここまで結合」：1 枚目からその画像までを結合。複数ページ分をまとめて読み込んだときに、1 ページずつ処理できます。
- **つなぎ目の微調整**：プレビューの各つなぎ目の左右にハンドルがあり、上のハンドルで上の画像の下端を、下のハンドルで下の画像の位置を、直接ドラッグして調整できます（元画像の範囲を超えることはありません）。右側の丸いボタンでつなぎ目の線とハンドルを隠し、仕上がりを確認できます。
- **書き出し**：PNG / JPG で保存できます。スマートフォンでは共有メニューから写真アプリにも保存できます。
  - ファイル名は「1.png」から始まり、ダウンロードするたびに末尾の数字が自動で 1 つ増えます（例：`abc-1` → `abc-2`）。新しい画像を読み込むと「1」に戻ります。
  - 「保存後、使用した画像を一覧から削除」にチェックを入れると、書き出しに使った画像が一覧から自動で消えるため、すぐに次のページの作業に移れます。

## 複数ページをまとめて処理する流れ

1. 全ページ分のスクリーンショットをまとめて読み込む
2. 1 ページ目の最後の画像の下にある「ここまで結合」を押す
3. プレビューを確認し、必要ならつなぎ目のハンドルで微調整する
4. 「結合して保存」で書き出す（「保存後、使用した画像を一覧から削除」をオンにしておく）
5. 次のページについて 2〜4 を繰り返す。ファイル名は 1.png、2.png、3.png… と自動で増えていきます

## 自動結合をうまく使うコツ

自動検出は「重なり部分がピクセル単位で一致すること」を前提にしています。

- できるだけ **端末標準のスクリーンショット機能** で撮影してください（全画像が同じサイズになります）
- PC のブラウザで撮る場合は、範囲選択ではなく **ウィンドウ単位のキャプチャ** を使い、すべての画像の幅をそろえてください
- スクロールするときは、前の画像と **1/4 画面程度の重なり** を残し、画面が止まってから撮影してください
- 幅が異なる画像は自動検出の対象外です。その場合は手動でトリミングするか、つなぎ目のハンドルで調整してください

## 開発

```bash
npm install
npm run dev
```

## デプロイ

`npm run build` で `dist/` に静的ファイルが出力されます。相対パスで出力されるため、次のどちらにもそのまま配置できます。

- **GitHub Pages**：リポジトリの Settings → Pages → Source で「GitHub Actions」を選択します。`main` に push すると `.github/workflows/deploy.yml` によって自動で公開されます
- **Vercel**：リポジトリをインポートするだけで動きます（Vite として自動認識されます）

## 自動検出のしくみ

各画像を横方向に数十列のグレースケールに縮小し、行ごとの「シグネチャ」を作ります。スクロールして撮った隣り合う 2 枚は、内容が上下に d ピクセルずれているだけです。
そこで、候補となる d ごとに連続して一致する最長の区間を探し（文字や輪郭のある行だけを数え、空白行や単色の領域は除外）、上位の候補を 256 列の精密な比較で確認します。
一致区間の終わりがつなぎ目になり、上の画像はそこまで、下の画像はそこから使います。重なり部分に同じ内容が繰り返し現れる場合（同じ見た目のリスト項目など）は結果が一つに定まらないことがあり、その画像に確認を促すメッセージが表示されます。

## 既知の制限

- ブラウザの canvas にはサイズの上限があります（iOS Safari で約 1,677 万ピクセル）。超える場合は書き出し時に自動で縮小され、パネルにその旨が表示されます
- 自動検出は、隣り合う画像の幅が同じ場合のみ動作します
