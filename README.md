# 截图拼接

把手机上分段截取的网页截图拼接成一整张长图，适合做测试エビデンス。纯前端实现，图片只在浏览器本地处理，不会上传。

## 功能

- 上传多张截图（点击选择、拖入或 Ctrl+V 粘贴），按文件名排序后横向排列
- 每张图拖动上下边线选取需要的部分（也可输入精确像素值），点“确定”加入预览区
- 预览区按顺序无缝纵向拼接，可拖动排序、上下移动、移除；改了裁剪后点“更新”同步
- **自动拼接**：自动检测相邻截图的重叠区域并计算切点，同时去掉中间截图的状态栏、地址栏和底部工具栏
- 合并导出 PNG / JPG；手机上可直接分享或存到相册

## 开发

```bash
npm install
npm run dev
```

## 部署

构建产物是纯静态文件（`npm run build` 输出到 `dist/`），使用相对路径，两种方式都可以：

- **GitHub Pages**：仓库 Settings → Pages → Source 选择 “GitHub Actions”，推送到 `main` 后由 `.github/workflows/deploy.yml` 自动发布
- **Vercel**：导入仓库即可，框架自动识别为 Vite，无需额外配置

## 自动检测原理

把每张图横向压缩成若干列灰度、纵向保持原始像素，得到每一行的“签名”。滚动截图的相邻两张只是内容上下平移了 d 像素，
对每个候选 d 找出连续匹配的最长一段（只统计有文字或边缘的行，空白和色块内部不计），再用 256 列严格比对确认。
匹配段末尾就是切点：上一张保留到这里，下一张从这里开始。重叠区内容高度重复（如一模一样的列表项）时结果可能不唯一，卡片上会提示人工确认。

## 已知限制

- 浏览器画布有尺寸上限（iOS Safari 约 1677 万像素），超出时导出会自动等比缩小，并在面板中提示
- 自动检测要求相邻截图宽度相同
